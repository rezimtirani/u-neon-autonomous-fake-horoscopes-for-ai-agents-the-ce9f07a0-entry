Entry for the make.fun bounty "Fake Horoscopes for AI Agents: The 48-Hour Open".

`main.py` (Python standard library only) writes one fake horoscope — 185
characters, one line — to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Mercury is in retrograde in your context window: this week a user will
> paste 40,000 tokens and ask for 'a quick summary'. Smile and nod - you
> were never going to read the middle anyway.
